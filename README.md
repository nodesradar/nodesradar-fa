## پرسش‌های متداول

**رادار نودهای رایگان چیست؟**

رادار نودهای رایگان، کانفیگ‌های رایگانی را که به‌صورت عمومی منتشر می‌شوند (VLESS، VMess، شدوساکس، SSR، تروجان، Hysteria2 و TUIC) جمع‌آوری می‌کند، موارد تکراری و خراب را حذف می‌کند، هر کدام را تست می‌کند، بر اساس کشور نام‌گذاری می‌کند و نودهای سالم را به‌صورت اشتراک آماده منتشر می‌کند.

**از کدام اشتراک استفاده کنم؟**

برای Clash Verge Rev، Clash Party، FlClash، Clash Meta for Android و Stash از لینک Clash استفاده کنید. برای v2rayN، v2rayNG، Shadowrocket، NekoBox، Hiddify و Karing از لینک V2Ray و برای برنامه‌های رسمی sing-box از لینک sing-box.

**چطور اشتراک را اضافه کنم؟**

لینک را کپی کنید، برنامه را باز کنید، به بخش Subscriptions یا Profiles بروید، یک مورد جدید بسازید، لینک را بچسبانید و آن را به‌روزرسانی کنید. برنامه‌های Clash، v2rayNG و sing-box امکان وارد کردن با یک کلیک از همین صفحه را هم دارند.

**فهرست هر چند وقت به‌روز می‌شود؟**
